# Chess Review Lab

An installable phone app for reviewing chess games move by move with Stockfish 19 (lite, WebAssembly). Games and notes are stored on the device.

Engine: Stockfish 19 via stockfish.js (GPL-3.0, see STOCKFISH-LICENSE.txt). Board logic: chess.js 0.10.3 (BSD-2-Clause, see CHESSJS-LICENSE.txt).
